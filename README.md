# Prototype of New Google Scholar Labs Feature 

An interactive product prototype exploring how Google Scholar Labs could help researchers compare studies and verify information against source evidence.

## Key Features

- Compare multiple studies side by side
- Review study design, population, outcomes, findings, and limitations
- Trace extracted information back to supporting source evidence
- Explore comparisons within the existing Scholar Labs experience

## Live Prototype

Use the website link in the **About** section of this repository to explore the interactive prototype.

## About This Project

This prototype was created as a product management case study exploring opportunities to make academic research comparison more efficient and verifiable.
